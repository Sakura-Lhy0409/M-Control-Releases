# 常见问题（FAQ）

## 安装与启动

<a id="q1-安装后打不开怎么办"></a>
### Q1：安装后打不开怎么办？

先保留 `%LocalAppData%\M-Control\error.log`，记录 Windows、显卡驱动及应用版本。

- 当前程序需可用的 .NET Framework 4.6.2 或兼容的更高 4.x 版本。
- 普通版需要系统 WebView2 Evergreen；可修复该运行时，或选择同版本 Fixed 安装版。Fixed 版内嵌浏览器运行时，不等于包含所有系统依赖。
- 若安全软件拦截，先核对下载来源、SHA256 和拦截原因。
- NVIDIA 6xx 曾因 GPUMON 私有 NVAPI 导致启动崩溃；v1.3.49 已增加门禁。若仍失败，附上驱动版本和故障模块，不能仅凭“闪退”认定原因相同。
- 重复启动通常唤醒现有窗口，后台启动参数不强制弹窗。

[官方下载](https://github.com/Sakura-Lhy0409/M-Control-Releases/releases) · [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) · [.NET Framework](https://dotnet.microsoft.com/download/dotnet-framework/net462)

<a id="q2-提示权限不足怎么办"></a>
### Q2：提示权限不足怎么办？

当前程序清单请求管理员权限，启动时需要同意 UAC。权限不足、驱动不可用和机型不支持是不同问题；管理员权限不会让不支持的接口变得可用。便携版不会自动安装 PawnIO，依赖该路径的功能需安装对应驱动或使用正式安装版。

## 功能与硬件状态

<a id="q3-某个功能显示灰色不可用"></a>
### Q3：某个功能显示灰色或不可用？

检查页面给出的原因：能力未知、缺少有效读数、供电条件不满足、HDR 开启或驱动接口不可用。参考[兼容性列表](COMPATIBILITY.md)。

程序已使用自研 MSI ACPI 客户端和 MOF 注册资源，不要求重新安装 MSI Center 来提供旧 DLL。若 WMI 类缺失，优先导出诊断，区分系统 ACPI/WMI 故障、注册失败和某个方法本身不支持；不要直接清空 WMI repository。

### Q4：和 MSI Center / SteelSeries GG 会冲突吗？

同时写同一硬件功能可能互相覆盖。使用 M-Control 控制风扇、场景、校色或灯效时，避免其他软件持续接管同一功能。GG 不是必需依赖；系统已有的高级 KLC 通道可以被复用，但 M-Control 不安装 SteelSeries 驱动。

<a id="q5-风扇曲线怎么调才合理"></a>
### Q5：风扇曲线怎么调才合理？

先读取当前硬件曲线，再小幅调整并观察温度、实际 RPM、噪音和稳定性。不同 CPU/GPU 的温度上限不同，不能用一套固定温度或通用曲线替代机型验证。

“恢复启动曲线”回到本次启动后、首次写入前的硬件快照；不会重置 BIOS 出厂设置。“保存配置”是本地收藏，“应用曲线”才写硬件。手动曲线启动恢复按最近成功应用状态处理。

百分比显示需要校准，基准文件为 `%LocalAppData%\M-Control\fan-calibration.json`。校准不是给固件所有 duty 值建立精确 RPM 映射。

### Q6：卸载或重置配置应注意什么？

先退出主窗口及需要停止的后台宿主，备份 `%LocalAppData%\M-Control\` 中需要保留的设置、日志和校色资料，再通过 Windows 卸载入口处理应用。不要整目录删除不明资料，也不要清理其他项目的 Temp。

PawnIO 可能被其他工具共用，不应作为卸载 M-Control 的必然清理步骤。自研 MOF 的卸载恢复由安装维护流程处理，不手工删除未知注册项。

### Q7：GPU 切换、电池和驱动页面在哪里？

GPU 模式在“性能”页；电池健康、上限及校准在“设置”页。GPU 支持项由能力位决定，旧双模式设备不显示纯核显；立即生效可能需要 S5 关机自动唤醒，而非普通重启。

“驱动更新”页只提供 MSI 支持页、BIOS、驱动和说明书链接，不是程序内驱动下载安装中心。

## 兼容性与反馈

### Q8：哪些机型经过测试？

查看[按机型和模块记录的证据](COMPATIBILITY.md)。单个灯效、快捷键或监控功能通过，不代表整个系列、所有 BIOS 或所有功能通过。旧文档没有证据的“全功能支持”结论不作为当前认证。

### Q9：能在非 MSI 设备上运行吗？

项目面向 MSI 笔记本。通用监控可能有读数，但 EC、场景、GPU 模式与灯效不保证可用；不按品牌外的设备猜寄存器写入。老机型也不能只凭年份判定支持与否。

### Q10：如何报告 BUG？

通过程序内诊断入口导出 ZIP，或在不能启动时提供错误日志；在 [GitHub Issues](https://github.com/Sakura-Lhy0409/M-Control-Releases/issues) 附上完整机型/主板码、BIOS/EC、Windows、显卡驱动、应用版本和复现步骤。诊断报告需由你自行提交，不会自动上传。

### Q11：为什么 HDR 开启时不能校色，或更新显卡驱动后颜色闪烁？

LM / True Color 使用 SDR 校色路径，HDR 开启时暂停写入。内屏停用也不会将校色错误应用到外接屏。

NVIDIA 6xx 对 Gamma Ramp 存在延迟变换；v1.3.49 替换发布修复采用稳定后的读回基准、重写节流和容差。该修复仍需受影响设备复测；若问题持续，记录是否 HDR、显示拓扑、驱动版本及具体安装包来源。

### Q12：检查更新为何失败，Fixed 版会变成普通版吗？

客户端读取固定 `updater/update.json`，尝试配置的 GitHub/镜像地址，并检查版本、附件名、大小和 SHA256。网络失败、清单未刷新和已忽略版本应分别判断。

Fixed 安装版选择 Fixed 更新附件；附件缺失或运行时目录不完整时会拒绝自动降级。手动下载时也应选择同类型安装包。

### Q13：退出窗口后为什么仍有 M-Control 进程？

关闭到托盘、完全退出和保留后台效果由不同设置控制。实时灯效、校色或非默认计时器精度可能需要同一 exe 的隐藏 worker。再次打开窗口不会重复部署既有灯效；需要停止时使用相应设置和退出入口。

v1.3.50 修复隐藏弹窗误阻断深休眠：在仪表盘等无编辑、无弹窗、无进行中操作的安全页面最小化约30秒后，可释放本程序 WebView2 并在打开时重建。未保存的风扇/灯效/校色编辑继续保留；不要手动结束其他程序共用的 WebView2 进程。
