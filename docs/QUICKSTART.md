# 快速开始指南

本指南对应当前正式 WinForms / WebView2 版本。功能按机型、固件和驱动能力开放；不可用时先查看页面提示。

## 1. 下载与安装

从 [GitHub Releases](https://github.com/Sakura-Lhy0409/M-Control-Releases/releases) 下载：

| 文件 | 用途 |
| --- | --- |
| `MControl_v<版本号>_Setup.exe` | 普通安装版；检查依赖，缺少 WebView2 时按安装器提示安装 |
| `MControl_v<版本号>_Setup_WebView2_Fixed.exe` | 内嵌固定版 WebView2，不依赖系统 Evergreen 来显示界面 |
| `MControl_v<版本号>_Portable.zip` | 解压运行；不会自动安装 PawnIO，完整硬件功能推荐安装版 |

以该版本实际附件为准，使用 `SHA256SUMS.txt` 核对下载文件。Fixed 版解决浏览器运行时依赖，仍需可用的 .NET Framework 4.6.2 或兼容的更高 4.x 版本及平台驱动。

运行安装器，默认目录为 `C:\Program Files\M-Control`。从 v1.1.0 及以后版本可覆盖升级；更早版本先卸载再安装当前版本。启动 `MControl.exe` 时按清单请求管理员权限，需要同意 UAC。

M-Control 使用自研 MSI ACPI 客户端及 MOF 资源，不要求安装 MSI Center。保留系统正常工作的芯片组、显示和 ACPI 设备驱动。

## 2. 查看仪表盘

仪表盘显示 CPU/GPU 温度、频率、功耗、电池和风扇状态；扩展传感器按实际能力显示。正在读取、无有效读数和不支持是不同状态，不要将问号理解为零。

风扇显示可切换 RPM 和百分比。百分比以校准得到的满速 RPM 为基准，首次开启需完成校准；未完成时继续使用 RPM。

## 3. 性能和显卡模式

在“性能”页选择平衡、安静、高性能或节能场景，等待成功提示及状态读回。电源计划和 MSI 场景是两个独立设置；部分扩展能力仅在匹配设备上出现。

同页的 GPU 模式按硬件能力显示核显、混合、独显选项。先保存工作，再选择“立即生效”或“稍后生效”。立即生效可能执行普通重启，也可能执行 S5 关机后自动唤醒，以当前弹窗为准。能力未知时不开放切换。

## 4. 风扇曲线

在“风扇控制”页分别选择 CPU/GPU。首次读取完成前显示加载状态，读取成功后才是当前硬件曲线。

- 横轴为温度，纵轴默认显示 RPM；曲线是固件策略，实际转速还受温度和固件控制影响。
- 切换手动策略后可拖动点或编辑表格；点击“应用曲线”才写硬件。
- “保存配置”管理本地收藏，与写入硬件不同。
- “恢复启动曲线”恢复本次 M-Control 启动后、首次风扇写入前捕获的硬件快照，不是 BIOS 出厂重置。
- 最近成功应用的手动曲线有独立的启动恢复机制，按机型及 CPU/GPU 分别保存。

校准包含风扇加速准备及约 30 秒采样，期间全速运转；完成后保存有效基准，可安全取消。不要直接套用其他机型曲线。

## 5. 电池、灯效和校色

**电池位于“设置”页。** 可读取健康信息、设置支持范围内的充电上限，或按提示执行校准。降低上限不会立即主动放电；校准期间按面板提示检查供电，取消请使用安全取消并恢复入口。

**灯效位于“灯光控制”页。** 仅显示设备支持的效果与区域。SteelSeries 和 Mystic Light 路线不同；PRISM 实时效果可能需要后台宿主持续运行，固件效果的保存能力也依机型而定。退出保持灯效由设置决定，不要将“应用”理解为所有设备都能永久写入键盘。

**屏幕校色位于对应校色页。** LM 导入和 True Color 根据活动内屏应用；True Color 需要匹配面板资源。HDR 开启时暂停 SDR 校色。NVIDIA 6xx 上应用校色会等待驱动稳定后确认，亮度预览仍即时更新。

## 6. 托盘、快捷键与更新

- 关闭窗口的行为由“设置”决定；最小化、关闭到托盘和完全退出不是同一操作。
- 右键托盘可打开或退出；退出后是否保留灯效由设置决定，启用的校色也可能由后台宿主继续维持。
- `Fn + ↑` 切换风扇全速，`Fn + F4` 切换触摸板；其他快捷键及 OSD 以“信息”页说明为准。
- “关于”页可检查版本或管理自动检查。Fixed 安装版自动更新保持 Fixed 类型，不自动降级成普通版。
- “驱动更新”页提供当前机型 MSI 官网、BIOS、驱动和说明书入口，不在程序内扫描或安装驱动。

## 7. 故障反馈

使用程序内诊断报告入口导出 ZIP；若无法打开界面，保留 `%LocalAppData%\M-Control\error.log`。需要详细日志时创建 `debug.flag` 并重启，排查完成后可将该标记改名停用。

反馈请提供完整机型、主板码、BIOS/EC、Windows、显卡驱动、M-Control 版本和复现步骤。诊断不会自动上传，确认内容后由你提交。
