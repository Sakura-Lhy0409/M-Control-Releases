# 兼容性与实机证据

更新日期：2026-09-08。本页按设备和具体功能记录证据，不将源码存在某条路由、单项测试通过或历史型号列表等同于整机全功能支持。

## 如何理解状态

- **实机通过**：有记录支持该机型的特定功能通过，仍受 BIOS、EC、驱动版本影响。
- **已修复，待实机验证**：代码和回归门禁已更新，尚无本页可引用的对应设备最终确认。
- **历史条目，待核实**：旧列表有记录，但缺少足够的版本、日志或测试来源。
- **能力未知/不支持**：以程序当次探测结果为准，不按年份、系列名或显卡数量猜测。

## 功能判定原则

| 功能 | 能力与限制 |
| --- | --- |
| EC / 场景 / 电池 | 依赖匹配固件接口、权限及可用访问路径；通用 ACPI 优先链与电池端口优先例外不同 |
| 风扇 | 曲线需可读写并能确认；百分比显示需要稳定 RPM 和成功校准 |
| GPU 模式 | 已按 UEFI `MsiDCVarData[5]` 和 legacy `0x2F` 能力位开放；旧双模式不推导纯核显，未知时禁止写入 |
| GPU 监控 | NVIDIA 驱动、NVML/SMI 等路径按可用性回退；不提供超频、锁频或游戏 FPS |
| SteelSeries | 按 PID、descriptor、物理/虚拟 KLC、ALC 和固件区分，不因 GG 白名单自动开放所有路由 |
| Mystic Light | 有独立分区协议适配；非 SteelSeries 键盘不意味着灯效全部不可用 |
| True Color / LM | 需要匹配面板资源和活动内屏；HDR 开启暂停 SDR 校色 |
| 快捷键 | 受 EC、WMI 事件与系统驱动影响；睡眠后需恢复订阅，不能只看 SCM 位 |

M-Control 不要求安装 MSI Center 或旧 MSI 官方运行时 DLL。自研 MOF 负责发布对应 WMI 契约，但不能补出固件本身不存在的方法。系统芯片组、ACPI 和显卡驱动仍需正常工作。

项目不以 MSI 台式机或其他品牌设备为支持目标；对老笔记本按实际接口判断，不以“2020 年前”一刀切。升级 BIOS/EC 前应遵循机型官方流程，本列表不要求为了试用软件而盲目升级固件。

## 提交兼容性反馈

在 [GitHub Issues](https://github.com/Sakura-Lhy0409/M-Control-Releases/issues) 提供：

1. 完整型号、主板码、BIOS/EC、Windows、M-Control 和显卡驱动版本。
2. 实际键盘 PID、是否安装 GG、是否外接屏，以及相关供电/HDR 状态。
3. 按模块列出可用与异常功能、操作步骤、读回结果，避免只写“全正常”。
4. 程序内导出的诊断 ZIP；由用户确认内容后自行提交。
