# M-Control v1.4.4 Hotfix

本次为相对 v1.4.3 的增量更新，正式基线仍为 v1.4.0。修复内容全部来自 v1.4.3 应用内提交的 BUG 反馈，感谢每一位附上诊断包的用户。

## 修复

- **托盘图标偶尔不出现**：开启“关闭到托盘”后，程序仍在运行却看不到托盘图标。现在资源管理器重启或开机登录较早时，托盘图标会自动恢复；每次隐藏到托盘前也会重新确认一次。
- **开机提示“未完成（宿主返回：null）”**：这条提示来自启动时读取风扇配置库的请求超时，并不代表风扇曲线写入失败。现在启动早期的回复不会再被丢弃，也不会再在开机时弹出这条误导性的提示。
- **自定义风扇曲线开机后需要切换性能模式才生效**：诊断显示部分机型的固件在开机约一分钟后会把风扇表重置为预设值。现在开机后 30 秒、90 秒、3 分钟以及插拔电源时都会复查，发现被改回才重新写入保存的曲线；自动模式下不会写入。
- **提示“未检测到 MSI WMI 硬件接口 / MSI ACPI 未就绪”且每次启动都无法恢复**：其他软件改动过接口注册后，残留的旧备份会导致修复流程一直拒绝执行。现在会把旧备份归档保留，并重新注册接口；已有可用的外部接口时仍不会覆盖。
- **旧款双模式机型切换独显后仍显示“混合模式”**：这类固件不会更新 UEFI 中的当前模式记录。现在改为根据内置屏幕实际连接的显卡和 EC 状态判断。
- **已经是独显模式时再次切换会直接重启**：现在只提示“已经是该显卡模式，无需重启”，不会再造成重启循环。
- **Alpha 17 等机型纯色灯效时 Scroll Lock 键颜色不变**：这些键盘实际带有 Scroll Lock 灯，现在会和其他按键一起设置颜色。GE78 等本来没有该键的机型不受影响。

## 已知情况

- 反馈“屏幕在白色和偏黄之间来回跳”的机器上，M-Control 的屏幕校色当时处于关闭状态，没有写入任何颜色设置。请先完全退出 M-Control 观察是否仍会跳动，同时检查 MSI True Color 的护眼/夜间模式和 Windows 夜间模式，再通过应用内反馈告诉我们结果。
- 旧款双模式机型的显卡切换写入方式没有改变；如果切换后内置屏幕仍由核显驱动，请开启诊断日志后完全关机再开机，并提交诊断包。

## 验证与边界

- 150 个 Node 测试文件、609 项 C# 测试通过，Release 构建 0 警告 0 错误；灯效已有报文逐字节未变。
- 以上修复均根据用户诊断包定位，开发环境不是 MSI 笔记本，尚未在反馈用户的机器上实机复测。欢迎更新后通过应用内反馈告知结果。
