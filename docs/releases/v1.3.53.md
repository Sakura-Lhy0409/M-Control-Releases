# M-Control v1.3.53

## 风扇配置命名与分享

- 保存配置时填写名称，已保存配置可重命名。
- 新增 JSON 导出/导入，包含机型、CPU/GPU 曲线和可编辑条件；不包含序列号或日志。
- 导入校验机型、文件版本、数据范围及条件列。成功后只加入配置库，请切换到对应风扇，在手动模式选择并点击“应用曲线”。
- 风扇页重新分组：控制模式与 CPU/GPU 切换、配置库与文件操作、恢复/保存/应用。名称输入只在小弹窗中出现，窄窗口按组换行。

## 新反馈修复

- MCBUG-00010：降档值必须低于同档升档值并逐档不递减；前端编辑、后端应用及启动恢复均有保护。机器读回值保留，软件原值传输，不擅自将默认 3 改写成温差。此固件对默认 3 的实际解读仍需用户温度/RPM 记录确认。
- MCBUG-00011：风扇表根据实际列数缩放，多条件表提供可用的水平滚动；矮窗口按视口限制表格高度，纵向滚动可以传递到页面。
- 手工反馈：补齐前台任务栏图标主题刷新，同步窗口大小图标与 Explorer 图标资源，保持窗口句柄。原反馈机器及固定任务栏按钮仍需用户复测。

## 启动默认页

“设置 → 启动与窗口”新增页面选择器，统一现有设置样式。选定后下次启动生效；默认仪表盘，从托盘恢复保持此前页面，不自动应用硬件配置。

## 验证与下载

新增 25 项 xUnit 行为用例通过；完整 xUnit 541/544、Node 143/145，剩余仍为此前登记的 3/2 项失败，未放宽原协议预期或同步等待预算。新增独立模块数量与 RPC 契约已登记。构建 0 警告/0 错误。

833×480 隔离浏览器实际验证命名、重命名持久化、默认页保存、降档限值，以及多条件表键盘/鼠标水平滚动与纵向末档访问。未将模拟曲线测试当成用户机器实测。

- `MControl_v1.3.53_Setup.exe`：普通安装版。
- `MControl_v1.3.53_Setup_WebView2_Fixed.exe`：内嵌 Fixed WebView2 安装版。
- `MControl_v1.3.53_Portable.zip`：普通便携版，不自动安装 PawnIO。
