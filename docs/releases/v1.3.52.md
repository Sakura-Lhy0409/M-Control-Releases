# M-Control v1.3.52

## 小窗口导航修复（MCBUG-00008）

- 修复隐藏的电池校准横幅仍在透明状态下拦截鼠标的问题。隐藏元素现在真正退出布局和点击层。
- 语言、设置、关于、信息四个入口改为与主导航一致的整行按钮。
- 取消侧栏强制空白占位，行高随窗口高度适配；窗口特别矮时可滚动侧栏，避免入口被裁切。

833×480逻辑窗口下，四个入口均通过中心命中和实际切页验证；833×380的滚动兜底、放大后导航也已验证。系统DPI、页面路由和仪表动效保留。

## 深色托盘透明图标（MCBUG-00009）

深色任务栏使用与Web图标同源的透明专用ICO，去掉固定颜色底板，适配Windows自动强调色。托盘按Windows系统主题选图，并独立管理图标，窗口主题刷新不会再将不透明窗口图标覆盖到托盘。窗口、安装器和浅色资源继续保留各自用途。

## 验证与下载

新增6项任务栏主题策略用例通过；ICO资源/尺寸、窗口和托盘路由、导航及前端生命周期门禁通过。全量Node142/144、xUnit516/519，剩余为此前已登记的2/3项失败，没有新增失败或放宽原有预期。Release构建0警告/0错误。

- `MControl_v1.3.52_Setup.exe`：普通安装版。
- `MControl_v1.3.52_Setup_WebView2_Fixed.exe`：内嵌固定版WebView2。
- `MControl_v1.3.52_Portable.zip`：普通便携版，不自动安装PawnIO。
- `SHA256SUMS.txt`：校验值。

反馈设备仍需安装新版验证实际150%缩放和任务栏自动主题色。此前两条GPU反馈仍待诊断资料，本版不宣称已解决其模式显示或150/175W问题。
