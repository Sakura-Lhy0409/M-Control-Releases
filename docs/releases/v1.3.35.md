# M-Control v1.3.35

发布日期：2026-07-28

本版本继续补强 CPU 温度读取链路：当 ThermalInfo 与 EC 都没有给出有效 CPU 温度时，仪表盘会按需启用 LibreHardwareMonitor 读取 CPU 子树温度作为兜底。

## 主要更新

- 新增 LibreHardwareMonitor CPU 温度兜底，优先选择 CPU Package / Tctl/Tdie / Core Max 等 CPU 子树温度。
- LHM 只在仪表盘需要且 ThermalInfo/EC CPU 温度都不可用时启动，不在非仪表盘页面额外打开传感器。
- CPU/GPU 温度 provider 统一过滤 `0/负数/超过 125°C` 等不可用读数，避免异常传感器值进入前端。
- 诊断日志增加 LHM CPU 温度值和具体传感器来源，方便后续判断某台机器到底是哪一路读到了温度。
- 增加 smoke 测试锁定 CPU 温度 fallback 顺序：`ThermalInfo -> LibreHardwareMonitor -> EC`。
