# M-Control v1.3.28

发布日期：2026-07-25

本版本修复 MSI Mystic Light 分区键盘错误显示 SteelSeries PRISM 分层控件的问题，并按 MSI 官方固件协议补齐 4/24/25/26 区键盘亮度控制。

## 主要更新

- 24 区 Mystic Light 键盘不再错误显示仅 SteelSeries PRISM 机型应有的“活动层”“响应层”和“闲置层”。
- 分层控件现在必须同时满足 `steelseries-native` 设备类型和 `prism` 效果目录；旧缓存即使残留错误标签，也不会让 Mystic Light 设备混入 PRISM 界面。
- 4/24/25/26 区 Mystic Light 键盘新增 0-4 档固件亮度控制，进入灯效页时会从键盘 MCU 读取当前档位。
- 应用灯效后写入亮度，并立即读取固件状态确认结果；读取使用 MSI 官方 `01 B1` Feature Report，写入使用 `01 B0 <level> 01`。
- 完整 Mystic Light 灯效仍明确标记为不可从硬件读回；新增的读回能力只覆盖 MCU 亮度档位。
- SteelSeries 设备现有亮度范围、PRISM 分层和灯效发送链保持不变。

## 发布包

- `MControl_v1.3.28_Setup.exe`：普通安装版，可直接覆盖升级。
- `MControl_v1.3.28_Portable.zip`：普通便携版，完整解压后运行。
