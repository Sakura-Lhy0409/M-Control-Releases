# M-Control v1.3.45

发布日期：2026-08-06

本版本修复 Titan GT77 HX（MS-17Q2）在 v1.3.44 中选择“脉轮（Chakra）”后，后置灯条正常响应但键盘整体熄灭的问题。

## 主要更新

- GT77 RPL 的 Chakra 键盘程序现在严格使用 SteelSeries GG 27 KLC config `516` 的正式键位分配，不再复用通用 Legacy 113 键表。
- 键位分配按正式配置拆为 `42 / 36 / 25` 三批，共 103 个唯一 HID；补入独立 CHERRY 标志 `0xE8`，并保留 `0x48` 禁用槽语义。
- Chakra KLC 改用 config `516` 对应的已校验 compiled program，避免专用程序与通用 assignment 混用导致固件拒绝或黑场。
- 修复仅作用于 `KlcConfigId=516` 的 Chakra 分支；后置 ALC config `499`、其它已工作的灯效、其它 Legacy 机型和通用 fallback 均保持不变。

## 发布包

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 普通包仍使用系统 WebView2 Runtime；系统 Runtime 缺失、损坏或无法更新时，请选择 Fixed WebView2 安装版。
- GT77 HX 用户升级后请重点复测“脉轮”：键盘、CHERRY 标志与后置灯条应同时正常；若键盘仍黑场，请停止继续切换并导出新的诊断包。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
