# M-Control v1.3.49

发布日期：2026-09-08

本 hotfix 修复 NVIDIA 驱动更新到 6XX 系列（如 616.56）后，M-Control 启动即闪退的问题。故障模块为 `nvapi64_impl.dll`，异常代码 0xc0000005，由 GPUMON 私有 NVAPI PowerMonitor 调用在驱动内部触发，托管代码无法捕获。

## 主要更新

- 新增 NVIDIA 驱动版本门禁：读取显卡设备类注册表中的 `DriverVersion`（如 `32.0.16.1656`），换算为 NVIDIA 营销版本（616）后，主版本 ≥ 600 时自动跳过全部 GPUMON 私有 NVAPI 调用。
- GPU 监控在跳过 GPUMON 后自动回退到 NVML / NVIDIA SMI / PawnIO 等公开链路，温度、功耗、频率与风扇监控保持可用。
- 新增启动参数 `--disable-gpu-nvapi`：任意驱动版本下强制禁用 GPUMON 私有 NVAPI 调用，供异常机型临时规避。
- 5XX 及更早驱动（如 572.xx）保持原有 GPUMON 读取路径不变。
- 修复已登记到 BUG 问题库 `BUG-20260908-001`，并配套 xUnit 与 Node 冒烟回归测试。

## 升级提示

- 已更新到 NVIDIA 6XX 驱动的用户可直接运行安装包覆盖升级；升级后重新启动 M-Control 即可恢复。
- 若个别机型在新驱动上仍有异常，可用 `MControl.exe --disable-gpu-nvapi` 启动以完全禁用 GPUMON 私有 NVAPI 通道。
- 请相关用户（issue #10 / #13）安装本版本后反馈实机结果。
