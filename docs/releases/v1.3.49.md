# M-Control v1.3.49

发布日期：2026-09-08

本 hotfix 修复 NVIDIA 驱动 6XX 系列（616.56 / 616.64 等）上的两个问题：

1. 启动即闪退：故障模块 `nvapi64_impl.dll`，异常代码 0xc0000005，由 GPUMON 私有 NVAPI PowerMonitor 调用在驱动内部触发，托管代码无法捕获。
2. 应用校色（True Color / LM）后屏幕色彩疯狂乱跳：6XX 驱动会对写入的 gamma ramp 做内部变换（实测读回最大偏差 1311），校色守护误判为"外部重置"，每 50ms 重写一次 ramp，导致持续闪烁。

## 主要更新

- 新增 NVIDIA 驱动版本门禁：读取显卡设备类注册表中的 `DriverVersion`（如 `32.0.16.1656`），换算为 NVIDIA 营销版本（616）后，主版本 ≥ 600 时自动跳过全部 GPUMON 私有 NVAPI 调用；GPU 监控回退到 NVML / NVIDIA SMI / PawnIO 公开链路。
- 新增启动参数 `--disable-gpu-nvapi`：任意驱动版本下强制禁用 GPUMON 私有 NVAPI 调用。
- 校色修复：6XX 驱动对 gamma ramp 写入是延迟变换（实测写入后约 0.4s~0.9s 才应用），原逻辑写后立即读回会采到变换前的中间值，与校色守护形成自激重写循环。现在写入后等待变换窗口（1500ms）再采纳生效基准，守护检测到外部修改后重写并采纳新基准，从根源消除乱跳。
- 校色重写节流从 50ms 提高到 1000ms，ramp 比较增加 ±2 容差，吸收驱动量化抖动。
- 5XX 及更早驱动（如 572.xx）保持原有行为不变。
- 修复已登记到 BUG 问题库 `BUG-20260908-001` / `BUG-20260908-002`，并配套 xUnit 与 Node 冒烟回归测试。

## 升级提示

- 已更新到 NVIDIA 6XX 驱动的用户可直接运行安装包覆盖升级；升级后重新启动 M-Control 即可恢复。
- 若个别机型在新驱动上仍有异常，可用 `MControl.exe --disable-gpu-nvapi` 启动以完全禁用 GPUMON 私有 NVAPI 通道。
- 请相关用户（issue #10 / #13）安装本版本后反馈实机结果。
