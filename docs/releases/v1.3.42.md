# M-Control v1.3.42

发布日期：2026-08-04

本版本补齐 MS-2651 在仅枚举 SteelSeries 物理 `PID_1167` 时的完整灯效路线，并修正灯效页“创意灯效”面板的显示条件。

## 主要更新

- 修复未安装或未运行 SteelSeries GG 时，MS-2651 只有物理 `PID_1167`、灯效页缺少 M-Control 实时灯效的问题；能力识别继续要求完整 HID 协议指纹，不仅凭 VID/PID 放宽写入。
- 修复 physical-only 路线把实时效果误发为旧 Legacy 报文并出现“应用成功但硬件未改变”的问题；实时纯色、逐键静态和动态效果现在使用正确的物理 Prism 报文。
- MS-2651 仅物理端点下的实时灯效现已同时驱动键盘、灯条和龙盾；保留原键盘顺序，并补齐六个外围灯区。
- 修复 physical-only 路线的固件效果目录、物理端点选择和 Flash 保存门；固件效果应用后按 `Fn+F8` 调整亮度仍保持当前配置。
- 固件报文、实时物理报文和 GG 逻辑报文继续使用各自独立的键表与封包，不再互相套用；能力不匹配时保持 fail-closed。
- 修复普通动态效果下“创意灯效”面板一直显示的问题；该面板现在只在“逐键静态”或“固件逐键静态”被选中时出现，省电接管和四区设备维持原有隐藏规则。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 普通包仍使用系统 WebView2 Runtime；系统 Runtime 缺失、损坏或无法更新时，请选择 Fixed WebView2 安装版。
- MS-2651 用户升级后请重新应用一次目标固件灯效，使配置按修正后的 physical-only 路线写入键盘。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
