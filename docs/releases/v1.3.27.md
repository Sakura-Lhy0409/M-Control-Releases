# M-Control v1.3.27

发布日期：2026-07-25

本版本修复部分机器缺少 MSI WMI 硬件接口时的启动卡顿、重复扫描和日志风暴，同时修正 WebView2 恢复页在高 DPI 下的文字裁切。

## 主要更新

- MSI WMI Provider 缺失时最多探测三轮；第三轮仍不存在后，本次运行立即停止扫描，下次启动再重新检测。
- 熔断后只显示一次功能不可用提示；点击“确定”只关闭提示，不会在本次运行中重新启用扫描。
- 将固定路径、类查询和 fallback 探活失败合并为每轮一条摘要，避免错误日志持续增长。
- 校色 `burstReapply` 改为后台合并调度，并使用 1500 ms 专用超时，避免占用 UI 消息链和 WebView2 的 15 秒初始化窗口。
- WebView2 原生恢复页的标题与状态文字改为自适应行高，高 DPI 下不再裁切或重叠。
- 本版本不会安装或补造机器缺失的 `MSI_ACPI/MSI_ACPI2` Provider；依赖该接口的部分功能仍可能不可用。

## 发布包

- `MControl_v1.3.27_Portable.zip`：普通便携版，完整解压后运行。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
- 如果提示 MSI WMI 硬件接口不可用，M-Control 已停止本次运行中的重复检测；重新启动程序后会重新探测一次完整的三轮流程。
