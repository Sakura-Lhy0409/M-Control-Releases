# M-Control v1.4.8 Hotfix

本版修复云端反馈中的风扇、睡眠恢复和性能模式菜单问题，正式基线仍为v1.4.0。

## 修复

- **Alpha 17 C7VG手动风扇**：曲线写入确认后补齐固件自定义模式激活，恢复保存曲线时也核对该状态；切回自动时读回确认，失败明确提示。
- **睡眠后的性能模式**：唤醒后恢复最后成功保存的场景和电源偏好。模式位未变但功耗策略被重置时重新提交一次；之后的用户操作会取消旧恢复任务。
- **托盘顺序**：与主界面统一为节能、安静、平衡、高性能、受支持的额外狂暴。
- **狂暴入口说明**：标明高性能对应官方Extreme Performance（中文也称狂暴）；托盘不再将未声明支持的额外APEX/Surge显示成灰色诊断入口。

## 复测

Alpha 17用户应用一组有明显区别的合理风扇曲线，观察实际转速是否随曲线变化，再确认自动模式可恢复。睡眠问题用户保存期望模式，睡眠唤醒后核对实际性能表现及显示；唤醒后新选择应优先生效。

GT77龙盾/尾灯和Vector A18后置灯反馈继续调查：GT77新版诊断仍没有后置控制器，官方同步恢复尚未实测；Vector现有附件只有26区键盘接口，缺少龙盾/后灯条接口身份与状态。本版不宣称这两项已恢复，也不发送猜测的EC或跨机型固件指令。
