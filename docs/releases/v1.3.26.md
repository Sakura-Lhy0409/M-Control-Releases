# M-Control v1.3.26

发布日期：2026-07-23

本版本修复 True Color 页面内部切换色温/模式时偶发短暂停顿的问题。

## 主要更新

- True Color 内部切换时，不再无条件停用已经未启用的 LM 校色，避免重复线性 Gamma 写入和配置解析。
- 校色命令完成后的生命周期同步只负责 display-color guard 的启停，不再立即重复发送第二次 Gamma reapply。
- 为 named pipe、display-color guard handler 和 host 调用增加 `[color-latency]` 分段耗时日志，便于继续定位个别机器上的慢点。
- 保留 v1.3.25 的崩溃修复：不恢复 WinForms UI 线程上的 native WinEvent hook。

## 发布包

- `MControl_v1.3.26_Setup.exe`：普通安装版，可直接覆盖升级。
- `MControl_v1.3.26_Portable.zip`：普通便携版，完整解压后运行。
- `SHA256SUMS.txt`：正式产物 SHA256 校验清单。

`v1.3.26` 属于 hotfix，不提供内嵌 Fixed Version WebView2 Runtime 的大型安装包。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
- 如果仍出现卡顿，请保留 `%LocalAppData%\M-Control\error.log` 中的 `[color-latency]` 行和发生时间。
