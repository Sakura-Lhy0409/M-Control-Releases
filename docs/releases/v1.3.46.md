# M-Control v1.3.46

发布日期：2026-08-10

本版本修复 Raider A18（MS-182L）多个动态 SteelSeries 固件灯效中 Scroll Lock、Page Up、Page Down 不同步的问题，并恢复该机型 Prism 实时灯效的三层控件。

## 主要更新

- 固件灯效现在持续使用由物理 KLC `PID_1122`、辅助 ALC `PID_1161` 解析出的有效 KLC `PID_205A` 与 Raider/Titan 18 正式键位布局，不再在 builder 内仅按物理 PID 退回通用布局。
- 修复覆盖固件 catalog、静态、逐键、Rainbow Split、Aurora、Gold Splash、Chakra、Disco、Reactive Key 以及现有厂内特例，不只针对单个动态效果。
- Scroll Lock `0x47`、Page Up `0x4B`、Page Down `0x4E` 现在进入全部相关固件 assignment；字节级门禁确认每个动态 builder 均生成 102 个正式键位。
- `steelseries-fw-basic + Prism` 路线重新显示活动层、响应层、闲置层；Legacy 路线仍保持单层。
- 修正灯效状态摘要重复显示为 `速度 5/10/10`，现在直接展示已经格式化的速度值。
- “蹦迪模式”曾短暂异常后自行恢复且无法稳定复现，本版本没有加入未经证实的机型特判。
