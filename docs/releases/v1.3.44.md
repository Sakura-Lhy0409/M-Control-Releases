# M-Control v1.3.44

发布日期：2026-08-06

本版本修复 Titan GT77 HX（MS-17Q1 / MS-17Q2）在 v1.3.43 中多数 SteelSeries Legacy 固件灯效无法应用的问题。

## 主要更新

- 为 GT77 HX 补齐 GG 17 与 GG 27 RPL 对应的 Legacy 固件配置，覆盖 `PID_204A`、`PID_2054` 及 `PID_1146/PID_114F` 后置灯条组合。
- 修复 GT77 因设备能力标志而被错误排除在固件配置部署路径之外的问题；固件效果现在按 GG 配置一次性下发，不转成软件逐帧动画。
- 修复 Aurora、Gold Splash、Chakra、Free Way、Drain、Aqua、白绿脉冲、红白响应、Disco、按键响应等效果不生效的问题；彩虹分裂继续沿用原有固件路径。
- 固件配置部署失败时直接报告失败，不再降级到不适用于该机型的动画路径，避免错误报成功或灯效被后续帧覆盖。
- 保持 GT77 物理键盘、后置灯条、CHERRY 标志与逻辑 GG 身份的既有路由不变，不影响其它 SteelSeries 机型。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 普通包仍使用系统 WebView2 Runtime；系统 Runtime 缺失、损坏或无法更新时，请选择 Fixed WebView2 安装版。
- GT77 HX 用户升级后请逐项验证上述固件灯效及后置灯条；若行为异常，请停止继续切换并导出新的诊断包。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
