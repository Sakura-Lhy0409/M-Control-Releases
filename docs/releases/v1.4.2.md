# M-Control v1.4.2 Hotfix

本次为相对 v1.4.1 的增量热修复，正式基线仍为 v1.4.0。

## 修复

- **快捷键误触发（0019）**：不再将 WMI 事件的时间戳、计数和实例名数值解释为按键；官方 MSI 事件码与 Windows 虚拟键码分开处理。
- **CPU 功耗通道恢复（0020）**：PawnIO 首次连接失败或 MSR 读取失败后按间隔重试，避免通道后来可用但必须重开软件。无有效采样时仍显示不可用；并非所有功耗缺失原因均已解决。
- **睡眠/休眠后的手动风扇曲线（0021）**：唤醒后检查并恢复最近成功应用的本机曲线；自动模式、安全模式和退出流程不自动写入，强冷期间延后恢复。
- **风扇页布局（0022、0023）**：修复窄窗口操作按钮分组失效；配置下拉列表完整显示长名称，允许换行和滚动。
- **新安装 Provider 校验失败（0025）**：修复旧固定哈希与当前构建资源不匹配导致的 `resource-integrity-failed`。校验值绑定本次实际构建资源，仍保留完整性检查和外部 Provider 保护。
- **退出节能后的灯条恢复（0026）**：恢复最后已应用的完整灯效及发送会话，不再只恢复亮度。该修复仍需反馈设备复测。
- **GPU 切换说明（0024）**：不再承诺所有设备关机后都会自动开机；确认窗口说明可能需要按电源键。本次没有修改 S5 硬件切换协议。

## 验证与边界

- Node 148 项及 xUnit 569 项通过，Release 构建 0 警告、0 错误。
- 隔离前端检查640/833/1024像素窗口的风扇按钮边界，中文及60字符英文长名称完整换行。
- 自动测试与隔离预览不代表全部客户机器已经实测通过。性能模式 UI 保持原样。

## 尚待定位的反馈

- **0024 雷影17自动开机失败**：需要 GPU 模式切换诊断与 `gpu_switch_debug.txt`，核对实际使用的切换路径；目前仅纠正错误承诺。
- **0027 泰坦16AI风扇不按配置运行**：需要完整型号/主板码、所选自动或手动模式、CPU/GPU曲线、温度与实际RPM，以及应用结果和诊断包。
- **0028 MS-15M3拔电黑屏**：需要复现后的诊断包、显示省电/True Color/LM/HDR设置、GPU模式，说明黑屏时系统和外屏是否仍运行。当前不能确认是刷新率、校色或显卡供电路径，未猜改固件。
- **0020功耗仍不可用时**：需要启动约30秒后的诊断包，查看MSR/PawnIO状态和功耗来源。
