# M-Control v1.3.50

本版处理“泰坦18 Pro 锐龙版2024”用户提交的四项反馈。修复复用当前硬件路由，不依据商品名新增未经验证的 PID 或寄存器写入。

## 修复内容

- **灯条休眠后恢复关闭状态（MCBUG-00001）**：灯效宿主使用能正常接收电源事件的 MTA owner，新增系统唤醒恢复，在设备就绪后重建 HID 发送会话并恢复最后已应用的配置；最多三次尝试，退出时取消。没有保存状态时不应用默认灯效。
- **深色托盘图标（MCBUG-00003）**：深浅色 ICO 不再是同一份白底图片。深色使用暗色圆角底和白 M，浅色/安装器保留原资源，产品橙色与几何不变。
- **150% 缩放布局（MCBUG-00004）**：纠正 WinForms DPI 设计基准；窄逻辑窗口下仪表对称双列，性能卡和风扇滑杆不再越界。保留系统缩放及圆环动效。
- **最小化后台占用（MCBUG-00005）**：修复隐藏父容器内的弹窗误被认定打开、阻断 WebView2 深休眠的问题。安全页面最小化约30秒后可以释放本程序界面，重新打开时恢复页面。

未保存的风扇/灯效/校色编辑、真实弹窗和进行中操作仍受保护，不无条件结束界面进程。其他软件的 WebView2 不会被强杀。

## 验证与复测

- 新增灯效恢复行为测试5项通过；JS语法与本次相关门禁通过。
- 853像素逻辑宽度下，仪表盘、风扇、性能、灯效、校色和设置页关键控件无横向越界；实际多屏150%环境仍需用户复测。
- 全量Node为142/144、xUnit为506/509；剩余是修改前已存在的质量预算和SteelSeries报文预期失败，本版未更改其预期来掩盖失败。Release构建0警告/0错误。
- 反馈机器尚无诊断附件、主板码或PID，四项均为“代码修复完成，待该设备复测”，不声明全机型实机验证完成。

升级后请分别复测：灯条关闭后的睡眠/休眠唤醒、深浅主题托盘图标、150%缩放和内外屏拖动、仪表盘最小化30秒后的占用及重新打开。
