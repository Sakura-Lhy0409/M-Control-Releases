# M-Control v1.4.5 Hotfix

本次修复 v1.4.4 的一条新增应用内反馈：Raider A18 HX A9WHG 已启用自启，但关机再开机后，电源计划和性能模式仍回到平衡。正式基线仍为 v1.4.0。

## 修复

- **电源计划记忆**：成功设置的 Windows 电源计划现在独立保存，并在下次启动时恢复，与 MSI 性能模式分别记忆。
- **启动后性能模式被改回**：启动后 30 秒、90 秒和 3 分钟会有限次数核对保存的设置；发现已确认的状态不同才恢复，读取不到状态时不会盲目写入。
- **后续手动切换优先**：启动后在应用内调整电源或性能选项，或使用场景模式热键，会取消本次自动核对，避免新选择被旧设置覆盖。
- **保持风扇恢复**：性能和电源核对经过与风扇控制相同的交易门；即使性能核对失败，原有风扇复查仍继续执行。

## 升级说明

旧版已经保存的 MSI 性能模式继续兼容。**旧版没有记录 Windows 电源偏好，升级后请重新选择一次电源计划**；收到成功提示后，该选择会用于之后的启动恢复。

## 验证与边界

- 150 个 Node 测试文件、623 项 xUnit 测试通过，Release 构建 0 警告、0 错误；新增 14 项恢复、并发、配置兼容和退出回归。
- 狂暴模式的设备支持门禁、硬件读写链路和既有报文字节保持原有契约。
- 修复依据来自用户诊断包及可执行回归；开发机不是反馈 MSI 设备，仍需实机复测。
