# M-Control v1.3.54

## 托盘快速控制

右键后台图标新增：

- 动态读取并切换已保存 CPU/GPU 风扇配置。
- 电源计划：最佳性能、平衡、最佳能效。
- 性能模式：高性能、狂暴、平衡、节能、安静，仍遵循机型能力门禁。
- 显卡模式：混合、独显直连、核显。
- 强冷开关，以及风扇、性能、设置、硬件信息快速打开入口。

所有操作复用已有控制器、读回和失败处理，不增加超频、锁频或未经验证的寄存器入口。

## CPU 频率反馈修复（MCBUG-00013）

AMD 移动平台优先使用 Windows Processor Frequency × % Processor Performance 的有效频率路径，避免 Ryzen 9 9955HX3D 在定频场景下 M-Control 显示 3.4 GHz、任务管理器显示 5.34 GHz 的口径差异。Intel/未知平台保持原有 Actual → LHM → IPF → WMI 回退顺序。
