# M-Control v1.3.47

发布日期：2026-08-12

本版本完成 Raider A18（MS-182L）固件动态灯效与 MSI 快捷键的实机收口，并修复 Fixed WebView2 安装版自动更新错误下载普通安装包的问题。

## 主要更新

- 修正 MS-182L 固件 descriptor 中 Print Screen `0x46` 与 Scroll Lock `0x47` 的空间坐标错位。九类空间动态固件效果现在使用独立程序槽与 `598` 单位 focal 补偿，保持原键序和其它键位不变。
- 补偿只作用于精确的 Raider 18 `PID_205A + PID_2059` 组合；特殊响应效果、静态效果和其它机型保持原报文。缺少源程序、槽位冲突、畸形报文或 focal 越界时拒绝发送部分修正。
- 睡眠唤醒后主动重建 MSI WMI 快捷键 watcher，并在新 generation 真正 ready 后重申 SCM 激活。修复唤醒后 `Fn+F7` 等快捷键失效、重新唤醒软件后才恢复的问题。
- Fixed WebView2 安装版自动更新时选择 `MControl_v{version}_Setup_WebView2_Fixed.exe`；普通安装版继续选择普通安装器。Runtime 残缺或清单缺少可信 Fixed 资产时拒绝静默降级。
- 普通安装器兼容旧 Fixed 客户端首次过渡升级：完整且由安装器拥有的 Runtime 会被保留并继续纳入托管清单，残缺 Runtime 不会被错误保留。
- 诊断包新增 `lighting-firmware-audit.log`，便于后续核对固件灯效实际下发链路。

## 发布包

- `MControl_v1.3.47_Setup.exe`：普通安装版，可直接覆盖升级。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 普通包使用系统 WebView2 Runtime；系统 Runtime 缺失、损坏或无法更新时，请选择 Fixed WebView2 安装版。
- 已安装 Fixed 版的用户从本版本起会继续下载 Fixed 安装器，不再自动降级为普通版。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
