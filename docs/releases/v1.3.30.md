# M-Control v1.3.30

发布日期：2026-07-25

本版本修复 Mystic Light 24 区键盘亮度上限显示错误，并增强 MSI WMI/ACPI 缺失问题的只读诊断证据。

## 主要更新

- 修复 MCU 已返回 `brightness=4, brightnessMax=4`，前端状态归一化后却显示为 `4/10` 的问题。
- 24 区 Mystic Light 现在保留后端提供的 0-4 固件亮度范围，页面应显示 `4/4`；不修改已验证的 MCU 亮度读写协议。
- 诊断包新增 `wmi_acpi_state.txt`，采集 `WmiAcpi` 服务与驱动、`ACPI\PNP0C14` 设备状态、已知 MSI `root\WMI` 类与实例、WMI repository 校验结果及近期相关系统事件。
- 增强诊断全程只读，不自动安装 MSI 官方组件，不修复 repository，不重启设备，也不执行任何 EC/WMI 硬件写入。
- 外部诊断进程复用现有有界进程执行器，包含超时、输出排空和进程回收，不增加无界等待。

## 发布包

- `MControl_v1.3.30_Setup.exe`：普通安装版，可直接覆盖升级。
- `MControl_v1.3.30_Portable.zip`：普通便携版，完整解压后运行。

## 升级与诊断提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
- 排查 ThermalInfo 安装/卸载导致 MSI WMI Provider 出现或消失时，请使用 v1.3.30 分别导出两种状态的诊断包；旧版本诊断包不包含新增的 `wmi_acpi_state.txt`。
