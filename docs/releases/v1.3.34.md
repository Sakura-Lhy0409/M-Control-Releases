# M-Control v1.3.34

发布日期：2026-07-28

本版本修复部分新平台在 CPU 温度暂不可读时，仪表盘把 EC 无效哨兵值显示成 `255°C` 的问题。

## 主要更新

- 修复 CPU/GPU EC 温度兜底未过滤 `0xFF` 的问题，避免无效值被显示为 `255°C`。
- 当 ThermalInfo 与 EC 都没有给出有效 CPU 温度时，仪表盘会保持无数据状态，不再显示误导性的极端温度。
- 增加 EC 温度哨兵值回归测试，锁定 `0/负数/0xFF/超过 125°C` 等无效温度不会进入监控快照。
- 补充 BUG 知识库记录，记录 Vector 16 HX AI A2XWHG / MS-15M3 现场诊断证据。

## 发布包

- `MControl_v1.3.34_Setup.exe`：普通安装版，可直接覆盖升级。
- `MControl_v1.3.34_Portable.zip`：普通便携版，完整解压后运行。
- `MControl_v1.3.34_Setup_WebView2_Fixed.exe`：内嵌微软官方 x64 Fixed Version Runtime 的安装版，适合系统 WebView2 缺失或异常的环境。
- `SHA256SUMS.txt`：正式产物 SHA256 校验清单。

`v1.3.34` 属于 hotfix；hotfix 可以提供 Fixed Runtime 安装版，但不提供 Fixed Runtime 便携 ZIP。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
- 这次修复只处理无效温度显示为 `255°C` 的问题；若某台机器所有现有 CPU 温度路径都不可用，升级后应显示为无数据而不是伪造温度。
