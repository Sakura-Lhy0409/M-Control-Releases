# M-Control v1.3.43

发布日期：2026-08-06

本版本新增 Titan GT77 HX（MS-17Q1 / MS-17Q2）的 SteelSeries 键盘灯效拓扑，补齐独立 CHERRY 标志与 29 区后置灯条，并修正 GT77 HX 13 代机型的实机端点识别。

## 主要更新

- 新增 GT77 HX `MS-17Q1` 与 `MS-17Q2` 灯效布局；两代机型共用正确的键盘、掌托 CHERRY 标志和后置灯条位置关系。
- 将独立发光的 `CHERRY` 标志加入键盘控制，使用 SteelSeries 正式描述符中的专用 HID 键位，不再误归到龙盾或普通键盘矩阵。
- 新增 GT77 专用 29 区后置灯条协议；实时层与固件活动层使用各自的正式报文布局，不复用其它 Titan/Raider 灯条封包。
- 修复 `MS-17Q2 + PID_113A/PID_1146` 实机组合被错误识别为旧代逻辑端点的问题；逻辑设备身份与实际物理发送端点继续分离，报文仍发往真实 HID 设备。
- 灯效页的 GT77 示意顺序调整为“龙盾、后置灯条、键盘”，CHERRY 独立显示在键盘左下方；当前没有可靠 HID 映射的龙盾保持只读展示，不猜测写入目标。
- GT77 路由继续要求机型、VID/PID 与 HID 协议指纹共同匹配；不满足完整证据时保持 fail-closed，不影响其它 SteelSeries 机型。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 普通包仍使用系统 WebView2 Runtime；系统 Runtime 缺失、损坏或无法更新时，请选择 Fixed WebView2 安装版。
- GT77 HX 用户升级后可在灯效页确认 CHERRY 与后置灯条区域；若后置灯条行为异常，请先停止写入并导出诊断包。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
