# M-Control v1.3.51

修复深色模式下关闭窗口进入托盘时，右下角提示窗圆角出现浅色锯齿边缘的问题（MCBUG-00007）。

提示窗现在同步使用当前主题的窗体底色，并在抗锯齿绘制前清理旧底色，避免边缘混入浅色像素。保留现有图标、圆角、字体、DPI缩放、不抢焦点和自动隐藏行为。

## 验证

- 100%、150%、200%DPI实际圆角可见区域像素测试，以及深浅主题切换测试，4项修复前失败、修复后通过。
- 托盘提示、Windows图标路由门禁通过，Release构建0警告/0错误。
- 全量Node142/144、xUnit510/513；仍为此前已登记的2项Node与3项SteelSeries测试失败，没有新增失败或放宽原有预期。
- 反馈设备为Vector 17 HX A13VHG；代码绘制缺陷已确认，但仍需该用户安装新版复测。若仍有白边，请提供原始截图、缩放比例及Windows内部版本，注明白边位于弹窗轮廓还是M图标。
