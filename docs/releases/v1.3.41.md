# M-Control v1.3.41

发布日期：2026-08-03

本版本集中修复旧 WebView2 Runtime 启动失败、MS-2651 SteelSeries 固件灯效与保存入口，以及多项 Fn 快捷键行为。

## 主要更新

- 修复系统 WebView2 Evergreen Runtime 较旧时，因缺少 `ICoreWebView2Settings9` 导致普通安装版或便携版启动后看不到界面的问题；删除无业务作用且默认已经关闭的可选设置，不吞掉其他启动异常。
- 修复 MS-2651 在 SteelSeries GG 环境下把亮度、固件部署和 Flash 保存错误发送到逻辑 `PID_2062` 的问题；实时帧继续使用 `2062`，固件控制严格使用具备已验证能力的实体 `PID_1167/MI_00`。
- 修复 MS-2651 固件纯色与固件逐键静态无法正确持久化的问题；应用成功后按既有协议保存一次，按 `Fn+F8` 改变亮度后不再恢复旧灯效。
- SteelSeries 路线不再显示或接受独立“保存到键盘”命令；固件效果由“应用”流程完成持久化，未知设备能力默认关闭，避免误入旧式保存写入。
- 省电模式接管键盘灯效时隐藏颜色、亮度、效果和编辑控件；固件灯效成功提示改为准确的固件层文案。
- `Fn+F1` 与 `Fn+F5` 现在会把扬声器/麦克风静音状态同步到机身指示灯；写入前读取 MSI DataCommand `45/44`，只修改目标位。
- `Fn+F5` 可切换默认麦克风静音，`Fn+F6` 打开蓝牙设置，`Fn+右箭头` 只关闭屏幕而不进入睡眠；`Fn+F7` 原有情景模式逻辑保持不变。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 普通包仍使用系统 WebView2 Runtime；系统 Runtime 缺失、损坏或无法更新时，请选择 Fixed WebView2 安装版。
- MS-2651 升级后请重新应用一次目标固件灯效，使新配置按修正后的物理端点写入键盘。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
