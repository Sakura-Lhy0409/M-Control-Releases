# M-Control v1.3.31

发布日期：2026-07-25

本版本正式加入自研 MSI WMI/ACPI Provider，并修复 Mystic Light 24 区逐键预览和响应式仪表图标布局问题。

## 主要更新

- 新增 clean-room 自研 MSI WMI/ACPI MOF Provider，不打包 `msiapcfg.dll`、MSIService、Service2、MSIWMIACPI2.dll 或 NBFoundation。
- 安装版默认注册自研 Provider；便携版和普通启动也会自动确保 Provider 可用。已有有效外部 Provider 不覆盖，检测到第三方改写时不抢回。
- 注册后优先通过系统 `mofcomp.exe` 热加载，成功时无需重启；卸载时仅在注册值仍由 M-Control 所有的情况下恢复旧值。
- 修复 24 区 Mystic Light 逐键编辑器第一排显示整串 `zone-1,zone-2...` 而不是区域编号的问题；不改变 HID 报文和区域顺序。
- 修复窗口缩小后 CPU/GPU 仪表小图标向左偏移的问题，使图标继续与固定圆弧、数字和单位共用中心线。
- 继续保留 Mystic Light MCU 官方 0-4 档固件亮度显示与写后确认。

## 发布包

- `MControl_v1.3.31_Setup.exe`：普通安装版，可直接覆盖升级。
- `MControl_v1.3.31_Portable.zip`：普通便携版，完整解压后运行。

`v1.3.31` 属于 hotfix，不提供内嵌 Fixed Version WebView2 Runtime 的大型安装包。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
- 自研 Provider 仍需按机型、BIOS/EC 和现有 MSI WMI 状态验证；卸载恢复和其他机型回归请保留诊断包。
