# M-Control v1.3.40

发布日期：2026-08-02

本版本修复仪表盘风扇标签异常着色，并为 MS-2651 的 SteelSeries 固件灯效补齐 KLC071 Flash 持久化。

## 主要更新

- 修复暗色模式下 CPU/dGPU 风扇切换到 RPM 后，“实时转速”标签单独变成橙色的问题；RPM/百分比切换、数值与动画保持不变。
- MS-2651 应用固件灯效成功后，会通过 effective PID `0x2062` 的 KLC071 通道将当前配置保存到键盘 Flash。
- 修复 MS-2651 按 `Fn+F8` 调整键盘亮度、睡眠唤醒或冷启动后，退回 SteelSeries GG 旧持久灯效的问题。
- Flash 保存只在用户成功应用受支持的固件灯效后执行一次，不接入启动、周期刷新、快捷键或唤醒路径；MS-1824 和其他 PID 保持原行为。
- 保存命令失败时会明确报告失败，不会把未持久化的灯效记录为成功。
- 新增 MS-2651 持久化策略、精确 65 字节保存报文、调用顺序与风扇标签样式回归测试，并登记 BUG 知识库。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- MS-2651 升级后请在灯效页重新应用一次目标固件灯效，使 `v1.3.40` 将当前配置保存到键盘 Flash。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
