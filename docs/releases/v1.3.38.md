# M-Control v1.3.38

发布日期：2026-07-28

本版本完善 CPU 温度与 NVIDIA GPU Hot Spot 温度读取链路，重点补齐 Intel MSR、AMD RyzenSMU PMTable 与 HWMonitor 同款多通道 Hot Spot 取值逻辑。

## 主要更新

- Intel CPU 温度新增 PawnIO `IntelMSR.bin` 只读链路，按 IA32 TjMax 与 Package/Core thermal status 解码，并位于 EC `0x68` 之后、DTT/IPF PackageTemp 之前。
- AMD CPU 温度新增 PawnIO RyzenSMU PMTable per-core max 链路，位于 ThermalInfo/EC 之后、LibreHardwareMonitor 之前。
- Fire Range `0x00621202` 按 16 核 PMTable 读取，active base `0x4B4`，core temperature base `0x534`。
- Dragon Range 明确拆成两条 profile：`0x00540004` 为 16 核，core temperature base `0x514`；`0x00540104` 为 8 核，core temperature base `0x4D4`。
- NVIDIA GPU Hot Spot 读取改为扫描前 4 路有效通道并取最大值，结果只进入扩展传感器，不改变 GPU 主温度。
- 诊断输出补充 AMD SMU profile、CPU core max 温度、core index/count 和来源，方便后续实机核对。
- 质量门禁登记新增 Intel CPU 温度只读 provider，避免把温度职责塞回 CPU 功耗 reader。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- Intel 或 AMD 机型如果此前 CPU 温度长期无法读取，建议升级后重新采集一次诊断包，确认实际命中的 provider。
- WebView2 经常异常的用户可优先使用 Fixed WebView2 安装版；普通用户继续使用普通安装版即可。
- 便携版不会自动覆盖自身文件，检查到新版本后会打开对应 Release 页面。
