# M-Control v1.4.3 Hotfix

本次为相对 v1.4.2 的增量更新，正式基线仍为 v1.4.0。

## 应用内提交 BUG 反馈

- 在 **设置 → 硬件诊断 → 提交 BUG 反馈** 中描述问题、填写复现步骤并直接提交，无需跳转网页或上传到网盘。
- 支持 ZIP / 7z 诊断包、MP4 / MOV / WebM 视频、PNG / JPG 截图及 TXT / LOG 日志。最多选择3个附件，单个不超过200MB；加上自动诊断包，总计不超过400MB。
- 可自动附上本机诊断包，也可取消勾选；截图和视频由用户自行选择，提交前需明确确认上传。
- 附件可追加、去重和逐个移除；超过限制时保留原选择。文字草稿自动保存在本机，失败或取消后保留内容。
- 显示上传进度，支持取消和重试；已完成的附件会跳过，丢失成功响应时先查询原反馈，避免重复建单。
- 提交成功后显示可复制的反馈编号，可用“反馈另一个问题”开始下一条；提供简体中文、繁体中文和英文表单。

## 上传与资料保护

- 附件通过 HTTPS 直传开发者私有加密存储；安装包中不包含云密钥，普通用户无法列出或读取他人的反馈。
- 机型和软件版本随反馈附带；诊断可能包含设置、日志、用户名及文件路径，请先检查所选截图、视频中的无关个人信息。
- 仅在用户确认提交后上传。核心硬件控制不增加自动遥测。

## 验证与边界

- 现行149个Node测试文件、581项C#测试通过，Release构建0警告0错误；反馈服务13项测试通过。
- 线上合成附件已验证创建/完成幂等、上传校验、禁止覆盖、未授权拒绝和私有下载SHA256；实际.NET Framework客户端上传ZIP及重复提交已通过。
- 退出应用后需要重新选择附件。取消不会删除可能已经收到的远端资料；反馈资料保存在私有后台，腾讯文档自动同步尚未启用。
- 本次没有修改性能模式布局、灯效协议或其他硬件控制行为。
