# M-Control v1.3.29

发布日期：2026-07-25

本版本修复 MSI WMI/ThermalInfo 探测把有效 Provider 误报为缺失的问题，并删除握手前不可靠的 `Get_Fan(0)` 预探活。

## 主要更新

- 修正 Vector 16 HX AI A2XWIG / MS-15M3 这类机器的 WMI 提示分类。
- 诊断证据确认：`MSI_ACPI Get_Data(0xD7)`、固定 `MSI_ACPI / ACPI\\PNP0C14\\0_0` 实例、自研 fallback 的温度/风扇读取以及 `MSI_Event` 均可用。
- `Get_Fan(0)` 本身没有坏；旧逻辑的问题是，在 `Get_WMI` 握手前使用临时 `GetMethodParameters` 对象调用它，部分有效 Provider 会拒绝这种参数对象。
- 实例发现阶段现在只检查方法契约；正式的 `Get_Fan(0)` 等读取统一在获取正确的 `Get_WMI -> Data.Bytes` 模板后执行。
- 如果实例存在但 ThermalInfo 能力探测失败，只停止本次进程的 ThermalInfo 重试，不再提示“MSI WMI 硬件接口不存在”。真正找不到 Provider 的机器仍保留三轮退避、会话熔断和一次性提示。
- 不修改 MSI ACPI 命令、EC/PawnIO 优先级、温度/风扇算法或硬件写入行为。

## 升级提示

- `v1.1.0` 或更高版本可直接运行安装包覆盖升级。
- 便携版不会自动覆盖自身文件；检查到新版本后会打开对应 Release 页面。
- 该版本修正了提示分类和探测顺序；现场机器升级后应不再因有效 WMI 通道弹出 Provider 缺失提示。
