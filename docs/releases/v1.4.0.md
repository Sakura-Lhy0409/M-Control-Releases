# M-Control v1.4.0 正式版

本次整合托盘、配置、设置、监控与诊断体验，保持 WinForms / WebView2 正式架构及既有硬件控制路径。

## 托盘与后台

- 托盘从版本化本地配置库读取 CPU/GPU 风扇配置，WebView 休眠后仍可使用。
- 显示真实电源计划、性能模式、GPU 模式、强冷勾选，以及电池/供电/充电上限摘要。
- 三语菜单、能力不足禁用、后台异步读取、操作中提示和主题通知。
- 风扇曲线、强冷、校准和场景切换共享串行控制；失败不盲目自动重放。
- 快速打开页面先等待界面恢复；重建不会把旧前端模式写回覆盖托盘选择。

## 配置与设置

- 风扇配置支持同名保存、异名另存副本、单独重命名、标签、排序和可见摘要。
- 配置状态比较曲线与策略内容，区分当前硬件、未应用修改、本地保存和与已确认硬件一致。
- 导入时预览机型、目标风扇和曲线，确认只加入配置库，仍需显式应用。
- 本地库使用原子写入、schema检查及大小限制，旧收藏迁移，未知版本不覆盖。
- 设置搜索、卡片分组、相关功能入口、首次使用说明，以及紧凑/标准/大字布局；保留圆环尺寸和原有动画。
- 通道状态分别来自 EC、MSI ACPI、PawnIO、管理员权限和 WebView，不相互推断。

## 监控、诊断与恢复

- CPU/GPU 频率、功耗携带实际采样时间；旧值标为缓存，15秒后失效。缺失风扇数据不会误报为停转。
- 展开查看来源/时间，错误提示可进入最近操作，复制运行状态报告。
- 主动导出诊断可附反馈编号、页面、时间、最近操作和有限前端错误；不自动上传。
- 重复告警合并计数，日志轮转保留上一份。
- 完全退出后使用 `MControl.exe --safe-mode` 进入只读恢复：停止已有组件、暂停自动恢复和硬件写入，不覆盖原配置；正常启动即可退出该模式。

## 验证

6个app脚本语法通过；147/147 Node、557/557 xUnit通过；Release构建0警告0错误。配置真实文件、并发串行、缓存新鲜度、日志限流、深浅主题像素和隔离浏览器交互都有对应回归。

旧测试问题经过审计：统一CRLF/LF测试读取；PID_1122物理帧补全PID_1161身份；Scroll Lock测试检查已验证焦点补偿的完整克隆字节与相位等价，原始RGB黄金值不变。没有为了测试改变HID协议。

本轮未新增硬件写入实测，自动测试不能保证所有机型/固件零缺陷。0014双风扇反馈根因仍未确认，界面仅提示已报告现象，不猜写独立PWM寄存器；原有GPU反馈继续保留待资料状态。
