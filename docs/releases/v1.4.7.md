# M-Control v1.4.7 Hotfix

修复 GT77HX 后置 Legacy 灯效误用其他机型灯区表的问题。

## 修复

GT77 的龙盾/尾灯控制器官方定义只有 29 个灯区。此前关闭、纯色、蹦迪及其他 Legacy 辅助灯效会按 GE68 的 53 区生成报文。本版统一使用 GT77 的 29 区表，并拒绝超范围的自定义灯区。

## 原反馈的恢复与复测

原反馈者已说明触发顺序为“蹦迪模式 → 后置灯失控 → M-Control 灯效页关闭 → 再开启后不亮”。本版修正已被实际生成器回归证实的超范围写入；它是否导致原机后置 USB 接口消失，仍待实机确认。

已经无法被系统或 GG 识别的后置接口，升级本版不能保证直接恢复。该反馈继续调查，优先核对官方 MSI Center“炫光同步”恢复识别线索；请勿反复重启正常键盘接口或提交相同 USB 采集。

接口重新出现后，再用本版依次验证纯色、蹦迪、关闭和开启，分别确认键盘、CHERRY、龙盾、尾灯。接口仍缺失时保留原反馈，不能把键盘可控视为后置恢复成功。
