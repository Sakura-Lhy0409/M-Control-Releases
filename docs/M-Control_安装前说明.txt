安装前请阅读

欢迎安装 M-Control。

M-Control 是面向 MSI 笔记本的第三方硬件控制台，以闭源免费方式发布，不隶属于 MSI。功能受机型、BIOS/EC、接口和驱动状态影响，不能将某系列名称当作全功能支持认证。

1. 系统和依赖

使用 Windows 10/11 x64。需要 .NET Framework 4.6.2 或兼容的更高 4.x 版本；安装器发现缺失会提示并可打开微软下载页，不会自动替你完成 .NET 安装。

普通安装版需要系统 WebView2 Evergreen；Fixed 安装版内嵌固定版 WebView2。按实际版本附件选择。安装版提供 PawnIO 安装流程；便携版不会自动安装驱动。

M-Control 使用自研 MSI ACPI 客户端和 MOF 注册资源，不要求安装 MSI Center，也不附带旧 MSI 官方运行时 DLL。系统 ACPI、芯片组和显示驱动仍需正常。

2. 权限和升级

程序清单请求管理员权限，启动时需要同意 Windows UAC。
v1.1.0 及以后可使用新安装器覆盖升级，复用安装目录；更早版本先卸载再安装当前版本。Fixed 安装版更新应继续选 Fixed 类型。

3. 使用边界

GPU 模式在“性能”页，按能力开放。立即生效可能普通重启，也可能 S5 关机后自动唤醒；切换前保存工作并阅读弹窗。

风扇曲线先读取后小幅调整，应用后观察真实 RPM、温度和稳定性。“恢复启动曲线”恢复本次启动首次写入前的快照，不是 BIOS 出厂重置。

电池上限与校准在“设置”页；按供电条件提示操作，校准使用安全取消及恢复入口。

PRISM 实时灯效可能需要后台宿主；固件永久保存能力取决于具体设备。LM / True Color 只应用于匹配的活动内屏，HDR 开启时暂停 SDR 校色。

避免多个程序持续写同一风扇、场景、灯效或校色功能。M-Control 主线的 GPU 遥测只读，不提供超频和锁频。

4. 校验、隐私和诊断

从正式 Release 下载并核对 SHA256。安全软件拦截时先检查来源和原因。
核心硬件控制本地执行，不做遥测或自动上传硬件信息。版本检查可由用户手动或设置自动触发，读取固定 updater/update.json 及配置镜像；确认更新后下载并验证安装器。打开驱动支持入口会访问 MSI 官网。

诊断 ZIP 由用户自行确认并提交。默认错误日志位于 %LocalAppData%\M-Control\error.log。
不要删除不明资料、csv/xlsx 或任何项目 Temp 内容；卸载 M-Control 不等于必须卸载其他程序共用的 PawnIO。
