# 在应用内提交 BUG 反馈

从 v1.4.3 起，打开 **设置 → 硬件诊断 → 提交 BUG 反馈** 即可提交，无需跳转网页、注册新账号或使用网盘。

1. 填写问题摘要、复现步骤和实际结果。一条反馈尽量描述一个问题；预期结果及联系方式选填。
2. 点击“添加截图 / 视频 / 日志”选择资料。可继续追加或单独移除附件，不用重新选一遍。
3. 默认附上诊断包，包含机型、系统、设置、应用日志及崩溃信息；不想附带时可取消勾选。截图和视频由你自行选择。
4. 检查资料并勾选上传确认，然后点击“提交反馈”。等待上传进度和最终收到提示。
5. 复制并保留`MCF-…`反馈编号，后续联系维护者补充资料时提供该编号。

## 附件限制

最多自行选择3个附件，可额外附上1个自动诊断包。单文件不超过200MB，含诊断包总计不超过400MB（按MiB计算）。支持ZIP、7z、MP4、MOV、WebM、PNG、JPG/JPEG、TXT和LOG。

超过限制时会说明原因并保留原选择。大视频可以先裁剪到出现问题的片段；截图和视频中的无关个人信息请先遮挡。

## 断网、取消与重试

- 文字草稿自动保存在本机。上传失败或取消后，填写内容和本次所选附件仍保留。
- 点击“重试提交”会先查询原反馈状态，跳过已完成附件，避免成功提示丢失后重复建单。
- 取消不会删除服务器可能已经收到的资料。退出应用后需要重新选择附件；当前不支持跨重启恢复上传进度。
- 提交成功后，用“反馈另一个问题”开始新反馈，原编号仍可用于后续沟通。
- 达到当天限额时，应用会提示稍后或次日重试，草稿不会因服务拒绝而清空。

## 资料如何保存

仅在你确认提交后上传反馈。附件通过HTTPS传到开发者的私有加密存储，维护者经授权后获取资料；其他用户无法浏览反馈或附件。诊断包可能包含用户名和文件路径，请按自己的意愿决定是否附带。

当前反馈保存在私有后台，腾讯文档自动同步尚未启用；提交成功以应用显示的`MCF-…`编号为准。核心硬件控制不增加自动遥测。
