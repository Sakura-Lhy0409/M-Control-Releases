安装完成

M-Control 已安装完成。启动时按 Windows UAC 提示授权管理员权限。

1. 查看仪表盘及功能状态
   等待读数完成。问号、无数据和不支持不代表真实零值。
   功能按当前设备能力开放，缺失时先查看页面提示与 FAQ。

2. 设置入口
   性能页：MSI 场景、电源计划、GPU 模式及受支持的扩展能力。
   风扇控制页：CPU/GPU 曲线、应用、保存配置与恢复启动曲线。
   设置页：电池健康、充电上限、校准和应用行为。
   灯光控制及屏幕校色：按设备能力操作；HDR 开启时暂停 SDR 校色。
   驱动更新页：MSI 官网支持、BIOS、驱动及说明书链接。

3. 托盘与后台
   关闭窗口行为由设置决定；最小化、关闭到托盘和完全退出不同。
   可通过托盘重新打开或退出。实时灯效、校色和计时器精度可能有独立后台宿主，保留与停止由对应设置控制。

4. 调整前后确认
   “恢复启动曲线”是本次首次风扇写入前的硬件快照，不是 BIOS 出厂曲线。
   GPU 切换前保存工作；按弹窗执行普通重启或 S5 关机后自动唤醒。
   电池校准期间遵循供电提示，取消时使用安全恢复入口。
   避免其他软件同时写入同一硬件功能。

5. 更新与排障
   关于页管理版本检查；Fixed 安装版保持 Fixed 更新类型。
   普通版界面异常先检查 Evergreen Runtime；Fixed 版检查内嵌 Runtime 完整性。
   .NET Framework 缺失时按安装器或微软页面提示安装，不能假定程序已自动安装。
   NVIDIA 6xx 崩溃/校色问题反馈时带上完整驱动版本和应用包来源。

   导出程序内诊断 ZIP，或保留 %LocalAppData%\M-Control\error.log。
   需要详细日志时创建 debug.flag 并重启；诊断资料不会自动上传。
